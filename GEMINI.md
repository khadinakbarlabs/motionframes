# MotionFrames

This extension makes animated videos. When the user asks for an animated short, reel, cartoon explainer or
character story, read `skills/motionframes/SKILL.md` in this extension's folder
(`~/.gemini/extensions/motionframes/`) and follow it. The engine is `engine/motionframes.mjs` in the same folder.

First time on this computer: run `node ~/.gemini/extensions/motionframes/engine/motionframes.mjs setup --test`.
It checks Node and FFmpeg, installs the free Kokoro voice, renders a 7-second test video and prints "ready".
