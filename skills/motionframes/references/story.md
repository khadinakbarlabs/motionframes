# Story

Write the script before any picture. Read it aloud: ≈3.7 words per second.

## Beat formulas

**Character story (ink cartoon, 40-60 s)**
Hook (the surprising fact, ≤ 8 words) → Setting (who, where, 1 line) → 3-4 escalating action beats →
Snap (the thing breaks) → "Luckily / Unluckily" turn → Analogy (make the science visible) →
Consequence → Callback twist (the last line pays off the first).

**Stickman "what if" explainer (38-40 s, 110-120 words)**
"What if..." hook → the common belief → "But..." → 2-3 concrete examples → the mechanism (one clear picture) →
payoff line. 10-12 setups of 2-4 s each, each setup a new picture.

**Hidden reason (30-45 s)**
Everyday object + "on purpose" hook → someone ignores the reason → it goes wrong → the real reason in one
picture → callback joke.

## Rules

- One idea per short. Cut every sentence that does not move the picture.
- Concrete numbers beat adjectives ("5 cm", not "a lot").
- Each voice line = one beat. Split lines where the picture changes; scenes anchor to words inside lines.
- Last 2 s: a picture worth pausing on (the twist), held, with the closing caption ≥ 2 s on screen.
- Show the script to the user and wait for an OK before building.
